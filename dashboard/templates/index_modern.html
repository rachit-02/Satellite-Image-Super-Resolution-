About CGA Model

Curvature-Guided Attention for Super-Resolution

What is CGA?

Curvature-Guided Attention (CGA) is an advanced neural network architecture specifically designed for satellite image super-resolution. It combines deep learning with attention mechanisms to achieve state-of-the-art performance.

The model uses curvature information to guide the attention mechanism, focusing on edges and important features that characterize satellite imagery. This allows it to recover fine details while maintaining global consistency.

How It Works

  1. Input: Low-resolution satellite image (64×64)
  2. Feature Extraction: Deep convolutional layers extract features
  3. Attention: Curvature-guided attention refines features
  4. Upsampling: Sub-pixel convolution upsamples to 4x
  5. Reconstruction: Output high-quality image (256×256)
